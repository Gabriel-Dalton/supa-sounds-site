Privacy policy for Supa Sounds Publisher

Last updated 25 October 2026.

What the application is

Supa Sounds Publisher is a private tool that uploads sound effect videos to the Supa Sounds YouTube channel and reads that channel's statistics. It is used only by the channel owner, on the channel owner's own Google account. It is not offered to the public and has no other users.

What Google data it uses

Through the YouTube Data API and YouTube Analytics API it uploads videos, sets their titles and descriptions, and reads views, likes and subscriber counts for the Supa Sounds channel only. The sign-in token is stored on the owner's computer and in the owner's private GitHub repository secrets. It is never shared with anyone else.

What it does not do

It collects no information about viewers or visitors. This website sets no cookies and runs no analytics. The application does not sell, share or transfer any Google user data to third parties, and does not use Google user data to train or improve any model.

Deleting data

The owner can revoke the application's access at any time at myaccount.google.com/permissions, which invalidates the stored token.

Google API Services User Data Policy

Supa Sounds Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions go to the channel owner through the Supa Sounds channel page.
